# Step 3: Client Domain Join
## Overview

This stage focuses on configuring the Windows client to communicate with the Windows Server domain controller and joining it to the Active Directory domain.

### Tasks
- [X] Configure the client's network settings.

### Key Learnings
This stage helped me develop an understanding of DNS configuration, network communication, and domain membership in a Windows environment. It also demonstrated how domain joining allows a client computer to participate in a centrally managed network and authenticate using domain accounts.
