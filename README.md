# Windows-Network-Lab

## Project Overview
This project involves building a basic network environment using Oracle VirtualBox, Windows Server, and a Windows client machine. The goal is to learn the fundamentals of Windows networking, server configuration, domain creation, and client integration within a virtual lab.

### Objectives
- Set up a virtual network using Oracle VirtualBox.
- Install and configure Windows Server.
- Install a Windows client machine.
- Configure the server with a hostname.
- Create and configure an Active Directory domain.
- Connect the Windows client to the domain.
- Test network connectivity and domain functionality.
- Document each stage of the setup and troubleshooting process.


### Tools and Technologies
- Oracle VirtualBox – Virtualisation software used to run the machines.
- Windows Server – Used to provide server services and manage the network.
- Windows 10 Pro – Used to simulate a workstation connected to the network.
- Active Directory Domain Services (AD DS) – Will be configured to manage the domain, users, and computers.
- DNS (Domain Name System) – Will be used for domain name resolution.
