# Step 1: Server and Domain Setup

## Overview
This stage focuses on configuring Windows Server to act as a domain controller for the virtual network created in VirtualBox.

### Tasks
- [X] Rename the server.
- [X] Configure a static IP address.
- [X] Install Active Directory Domain Services (AD DS).
- [X] Promote the server to a domain controller.
- [X] Create a new Active Directory domain.

### Key Learnings
This stage will helped develop an understanding of Windows Server administration, static IP addressing,Microsoft Server Roles & Features, and the role of Active Directory in managing a network.
